### איך משחקים אחרי ההורדה
1. הורד את **`Hassidisher-Pakman-Windows.zip`** לשולחן העבודה / הורדות
2. אם Windows חוסם — **שמור בכל זאת**, ואז לחיצה ימנית על ה-ZIP → מאפיינים → **Unblock / בטל חסימה** → אישור
3. לחיצה ימנית → **Extract All / חלץ הכל** (אל תפתחו את ה-EXE מתוך חלון ה-ZIP!)
4. היכנסו לתיקייה **`Hassidisher Pakman`** ולחצו על **`Hassidisher Pakman.exe`**
5. אם SmartScreen מופיע: **More info** → **Run anyway**

לא צריך Java, לא צריך קומפיילר.

## מה יש במשחק

- **4 סדרים** — שחרית · סדר עיונא · סדר גירסא · סדר ערב
- **פרס בכל שלב** — תפילין, ספרים, כובע
- **לב נוסף** בשלבים 2–3 (+1 חיים)
- קושי שעולה לאט עם הניקוד
- **סאונד**, **השהיה (P)**, **השתקה (M)**
- תפריט בעברית וטבלת שיאים

## מקשים

| מקש | פעולה |
|-----|--------|
| חיצים | תנועה |
| P | השהיה / המשך |
| M | השתקת סאונד |
| ESC | חזרה לתפריט |
| Enter | אישור (סוף משחק / שיא חדש) |

## למפתחים

**דרישה:** JDK 17+

```bash
run.bat
```

בניית חבילת ההורדה מחדש:

