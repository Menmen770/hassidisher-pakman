### איך משחקים אחרי ההורדה
1. הורד את **`Hassidisher-Pakman-Windows.zip`**
2. חלץ (Extract) את התיקייה
3. לחץ על **`Hassidisher Pakman.exe`** — המשחק נפתח עם האייקון

לא צריך Java, לא צריך קומפיילר.

---

## מה יש במשחק

- **4 סדרים** — שחרית · סדר עיונא · סדר גירסא · סדר ערב
- **פרס בכל שלב** — תפילין, ספרים, כובע
- **סאונד**, **השהיה (P)**, **השתקה (M)**
- תפריט בעברית וטבלת שיאים

## מקשים

| מקש | פעולה |
|-----|--------|
| חיצים | תנועה |
| P | השהיה / המשך |
| M | השתקת סאונד |
| ESC | חזרה לתפריט |
| Enter | אישור (סוף משחק / שיא חדש) |

## למפתחים

**דרישה:** JDK 17+

```bash
run.bat
```

בניית חבילת ההורדה מחדש:

```bash
build-release.bat
```
